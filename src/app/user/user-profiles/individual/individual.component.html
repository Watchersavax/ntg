Confirm Identity

The system checks the first and last names provided by individual users against the official government biometric database. This can be done using the National Identification Number (NIN), Driver’s License, International Passport, or LAG ID, based on the user’s choice.

Users must ensure that the name they provide matches the one registered in the government records precisely.

Once verified, the e-affidavit platform will access the deponent’s Photo ID from the database and incorporate it into the generated affidavit.

Account Usage

This account is meant for individual use and can only be used to produce sworn affidavits on behalf of the account’s registered owner. No other person can make use an account once it has been registered under a specific name.
